# shopping-platform

一个简洁且精美的静态电商展示平台，基于 `商品清单_2000.csv` 渲染商品卡片。

## 功能
- 首次访问需输入用户名后进入平台
- 顶部分类快捷按钮 + 更多分类下拉菜单
- 商品搜索、价格/好评率排序
- 分页展示（默认每页 24 条）
- 每个商品都显示图片（优先使用 Wikimedia Commons 等正规来源图片，失败时自动回退到本地 SVG 占位图）
- 页面展示“正规信息来源”链接（京东/天猫/淘宝/拼多多/苏宁易购/Wikimedia Commons）

## 本地运行
```bash
python -m http.server 8000
```
然后打开 `http://localhost:8000`。
